# Shishoki YuE Studio — Public Update Feed

This public repository hosts `version.json` for the **Check Now** button inside Shishoki YuE Studio.

When you publish a new installer on Lemon Squeezy (e.g. `2.1.0`):
1. Edit `version.json` and update `"version"` to `"2.1.0"`.
2. Update `"download_url"` if needed (defaults to Lemon Squeezy Customer Orders portal `https://app.lemonsqueezy.com/my-orders`).
